# الفيديو اليومي: خطوات التنفيذ

اقرأ `BRAND.md` أولاً. هدف الفيديو اليومي: يشرح منتجاً واحداً من «رقّم» بزاوية مختلفة عن أي فيديو سابق.

## التنويع
المنتج حسب يوم الأسبوع بتوقيت بغداد:
- السبت: رقّم مِنيو • الأحد: رقّم حضور • الإثنين: رقّم شهادات • الثلاثاء: رقّم فوترة • الأربعاء: رقّم مواعيد • الخميس: رقّم ردّ
- الجمعة: أسبوع ISO زوجي = رقّم تدريب، فردي = رقّم لوحة

الزاوية = (رقم أسبوع ISO) mod 4:
- 0 = المشكلة التي يزيلها • 1 = كيف يشتغل بـ 3 خطوات • 2 = يوم من حياة زبون • 3 = النتيجة بالأسبوع الأول

قبل التنفيذ: اطّلع على `videos.json` وتأكد إن العنوان والفكرة ما تكرر فيديو سابق.

## السيناريو
4–6 مشاهد بالترتيب: المشكلة (الخطاف بأول ثانيتين) ← ما يفعله المنتج بجملة ← رقم هو حقيقة بالمنتج ← دعوة واحدة. بطاقة ختام: الشعار + «رقّم شغلك.» لا أكثر من 8 كلمات تقريباً بالمشهد. أرقام لاتينية. النص خارج أعلى 10% وأسفل 15% من الإطار.

## الإنتاج
- 1080×1920، 30fps، 20–35 ثانية، H.264 + AAC، `-movflags +faststart`.
- المشاهد HTML/CSS + Web Animations في `tools/scene.html`، تُرندر بـ `tools/render.py` (Playwright، `seek(t)` لكل فريم، وتمرير مباشر لـ ffmpeg). الموسيقى من `tools/audio.py` (numpy، بلا صوت بشري). `html, body` وكل مشهد `overflow:hidden`.
- ابدأ من `tools/scene.html` الحالي كقالب (دوال `pop` و`words` و`sceneWin` وأيقونات Lucide والشعار ومولّد QR)، واستبدل المشاهد. إذا كنت تحتفظ بفيديو سابق، انسخ `scene.html` إلى `tools/scenes/YYYY-MM-DD.html` قبل التعديل حتى يبقى مصدر كل فيديو.
- تحقق: `ffprobe` للدقة والمدة والصوت، واستخرج 4 فريمات وانظر إليها (العربي متصل وغير مقصوص) وأصلح وأعد الرندر عند الحاجة.
- التثبيتات: `pip install numpy playwright`، والمتصفح مثبّت (`/opt/pw-browsers/chromium`)، ولا تشغّل `playwright install`.

## الكابشن
نفس الأربعة أسطر بلهجة عراقية، ثم 8–12 هاشتاغ تشمل #رقّم #Raqqim #رقّم_شغلك واسم المنتج والقطاع ووسوم العراق/البصرة. إيموجي واحد كحد أقصى بالنهاية.

## التسليم
1. الفيديو: `raqqim-videos/videos/raqqim-video-YYYY-MM-DD.mp4`
2. إضافة سجل بأعلى `raqqim-videos/videos.json` بالشكل `{date, title, file, caption}`
3. الكابشن: `raqqim-videos/captions/raqqim-caption-YYYY-MM-DD.txt`
4. commit و push
5. أعطِ حسين: رابط الفيديو المباشر، رابط الصفحة، والكابشن كاملاً.
